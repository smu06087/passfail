# PassFail 프로젝트 프레젠테이션 가이드

이 문서는 'PassFail' 코딩 테스트 플랫폼 프로젝트를 초보자에게 설명하기 위한 PPT 구성안입니다.
각 슬라이드의 핵심 내용과 설명 스크립트를 포함하고 있습니다.

---

## [Slide 1] 제목 슬라이드
**제목: PassFail - 나만의 온라인 코딩 테스트 플랫폼 만들기**
**부제:** 스프링 부트(Spring Boot)로 구현하는 채점 엔진과 AI 코드 리뷰 시스템
**발표자:** [사용자 이름]

---

## [Slide 2] 프로젝트 개요
**내용:**
*   **목적:** 사용자가 알고리즘 문제를 풀고, 실시간으로 채점 결과를 확인하며, AI의 피드백을 받는 플랫폼
*   **주요 기능:**
    1.  회원가입 및 소셜 로그인 (Google, Kakao 등)
    2.  온라인 코드 에디터 및 실시간 컴파일/실행
    3.  AI 기반 코드 품질 분석 및 개선 제안
    4.  사용자 랭킹 및 티어 시스템

---

## [Slide 3] 전체 아키텍처 (초보자용)
**내용:**
*   **Spring Boot MVC 패턴:**
    *   **Controller (요청 처리):** 사용자의 클릭이나 데이터 입력을 받음
    *   **Service (비즈니스 로직):** "코드를 실행해라", "리뷰를 생성해라" 같은 명령을 수행
    *   **Repository (데이터 접근):** 데이터베이스(DB)에서 정보를 꺼내오거나 저장함
    *   **Entity (데이터 모델):** '회원', '문제', '제출' 등 실제 데이터의 틀

---

## [Slide 4] 회원 관리 & 보안
**내용:**
*   **Spring Security:** 안전한 로그인 환경 구축
*   **OAuth 2.0:** "내 구글 계정으로 로그인하기" 기능
*   **보안:** 비밀번호는 암호화하여 저장(Bcrypt), 이메일 인증을 통한 가짜 계정 방지
*   **초보자 포인트:** "비밀번호는 데이터베이스에 그대로 저장하면 절대 안 돼요!"

---

## [Slide 5] 코딩 테스트 엔진의 원리 (중요!)
**내용:**
*   **샌드박스(Sandbox) 실행:** 사용자가 보낸 위험한 코드가 서버를 망치지 않게 독립된 공간에서 실행
*   **실행 순서:**
    1.  사용자 코드를 임시 파일(`.java`)로 저장
    2.  `javac` 명령어로 컴파일
    3.  `java` 명령어로 실행 (시간 제한, 메모리 제한 적용)
    4.  출력 결과와 정답을 비교하여 성공/실패 판정
*   **초보자 포인트:** "무한 루프를 도는 코드가 들어오면 어떻게 할까요? -> 10초 뒤에 강제로 종료시켜요!"

---

## [Slide 6] AI 코드 리뷰 시스템
**내용:**
*   **Gemini / OpenAI 연동:** 최신 AI 모델을 활용한 피드백
*   **리뷰 과정:**
    1.  제출된 코드와 채점 결과를 AI에게 전달
    2.  "이 코드를 시니어 개발자처럼 리뷰해줘"라고 요청(프롬프트 엔지니어링)
    3.  AI가 시간 복잡도, 코드 품질, 개선안을 응답함
*   **초보자 포인트:** "혼자 공부할 때 막히면 AI 선생님이 답을 알려주는 느낌이에요."

---

## [Slide 7] 데이터베이스(DB) 설계
**내용:**
*   **핵심 테이블:**
    *   `Member`: 사용자 정보
    *   `Problem`: 알고리즘 문제, 제한 사항
    *   `Submission`: 사용자가 낸 코드와 결과
    *   `AiCodeReview`: AI가 생성한 리뷰 기록
*   **관계 설명:** "한 명의 사용자는 여러 번 코드를 제출할 수 있어요 (1:N 관계)"

---

## [Slide 8] 관리자 대시보드
**내용:**
*   **통계 시각화:** 오늘 방문자 수, 인기 있는 문제, 전체 회원 현황
*   **시스템 관리:** 문제 추가/수정, 비매너 사용자 관리
*   **초보자 포인트:** "전체 서비스가 어떻게 돌아가는지 한눈에 보는 관제탑이에요."

---

## [Slide 9] 마무리 및 느낀 점
**내용:**
*   **성과:** 복잡한 외부 프로세스 실행(컴파일러) 제어 방법 습득
*   **어려웠던 점:** AI API 연동 시 예외 처리, 보안 설정
*   **향후 계획:** 더 다양한 언어(Python, C++) 지원, 실시간 대결 모드 강화

---

### 💡 PPT 제작 팁:
1.  **이미지 활용:** 슬라이드 3에서는 MVC 패턴 그림을, 슬라이드 5에서는 샌드박스 실행 순서도를 넣으면 좋습니다.
2.  **코드 스니펫:** 슬라이드 5나 6에 실제 `CodeExecutionService`나 `GeminiCodeReviewService`의 핵심 코드 몇 줄을 넣으면 전문성이 높아 보입니다.
3.  **데모 영상:** 에디터에서 코드를 짜고 채점 버튼을 눌러 AI 리뷰가 나오는 과정을 영상으로 보여주면 가장 효과적입니다.
